**# B100 Financial Intelligence Dashboard**



**## Project Overview**



**This project builds an end-to-end Financial Intelligence Platform using Python, PostgreSQL, and Power BI. The solution extracts, transforms, and analyzes financial data from multiple datasets covering balance sheets, profit \& loss statements, cash flow statements, company profiles, and financial analysis metrics.**



**## Objectives**



**\* Build an ETL pipeline for financial datasets**

**\* Create a PostgreSQL data warehouse using a star schema**

**\* Calculate financial KPIs and metrics**

**\* Develop interactive Power BI dashboards**

**\* Generate business insights from financial performance data**



**## Tech Stack**



**\* Python**

**\* Pandas**

**\* PostgreSQL**

**\* SQLAlchemy**

**\* Power BI**

**\* Git \& GitHub**



**## Project Workflow**
