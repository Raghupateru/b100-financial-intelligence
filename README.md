# B100 Financial Intelligence Platform

## Project Overview
End-to-end Financial Intelligence project built using Python, PostgreSQL and Power BI.

## Tech Stack
- Python
- Pandas
- PostgreSQL
- Power BI
- Git
- GitHub

## Project Architecture

Raw Data
↓
Python ETL
↓
Data Cleaning
↓
Financial Metrics
↓
PostgreSQL Warehouse
↓
Power BI Dashboard

## Key Features
- Profitability Analysis
- Cash Flow Analysis
- Financial Health Analysis
- ROE & ROCE Tracking
- Debt-to-Equity Analysis
